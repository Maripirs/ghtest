Commands

  • git status: see what changed and what's staged
  • git diff: show exact line changes not yet staged
  • git add: stage changes for the next commit
  • git commit: save a snapshot of staged changes
  • git log: browse the commit history
  • git switch: move to another branch
  • git branch: list, create, or delete branches
  • git pull: fetch and merge your teammates' work
  • git push: upload your commits to GitHub
  • git fetch: download new commits without merging
  • git stash: park unfinished work for later
  • git restore: discard changes to a file

The everyday loop

  1. Branch off main for each change.
  2. Commit small, focused snapshots.
  3. Push the branch and open a pull request.
  4. Review, merge, and pull main again.

Glossary

Repository
A project folder plus its full history of commits.
Commit
A saved snapshot of your files, with a message and an id.
Branch
A movable label pointing at a commit. New work goes on a branch.
HEAD
Where you are right now: the branch or commit you have checked out.
Remote
A copy of the repository hosted elsewhere, usually GitHub, named origin.
Pull request
A request to merge one branch into another, with a place to review it.
Merge conflict
Two changes to the same lines that git can't combine on its own.
Staging area
The list of changes that will go into your next commit.
